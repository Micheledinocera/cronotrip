# Che cos'è?

Cronotrip vuole essere una via di mezzo tra un diario di viaggio e un gestore di viaggi.
Le funzionalità di base devono essere:
- Possibiltà di preparare itinerari
- Instanziare questi itinerari per creare dei Viaggi 
    - quindi un viaggio è una instanza di itinerario però in programma/in corso/trascorsa
- l'app è multi utente con possibilità di vedere e condividere gli itinerari degli altri
- l'utilizzo è quasi solo personale più altri pochi amici

# A che necessità risponde?

L'app nasce come risposta a 3 miei bisogni:
- il poter raccontare cosa ho fatto durante un viaggio avendo tutto dalla stessa parte (foto, prezzi, spostamenti, etc)
- avere uno storico dei viaggi fatti
- avere un unico punto dove salvare le info in fase di organizzazione del viaggio (ad oggi uso notion, magari poi ti faccio qualche screen/export di notion per farti capire cosa faccio di solito)
