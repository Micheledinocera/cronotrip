# Bun al posto di npm

Il progetto usa solo **Bun** come package manager e per lanciare gli script: niente più npm/npx.

- `bun install` al posto di `npm install`; il lockfile è `bun.lock` (migrato da `package-lock.json`, stesse versioni), `package-lock.json` è rimosso.
- `package.json` fissa la versione con `"packageManager": "bun@1.4.2"`; la CI la legge da lì (`oven-sh/setup-bun`).
- Script: `bun run generate`, `bun run db:start`, `bun run db:reset`, `bun run db:photos`, `bun run dev:local`.
- Al posto di `npx` si usa `bunx` (es. `bunx supabase migration list --linked`, `bunx supabase migration repair ...`).
- Versione della release: `bun pm version <x.y.z> --no-git-tag-version` al posto di `npm version`.
- La CI fa `bun install --frozen-lockfile` e `bun run generate`. Node resta installato: la CLI di Nuxt gira ancora su Node (Bun fa da package manager e da runner degli script, non da runtime della build).
- Bun non esegue gli script di install delle dipendenze se non sono "trusted". Bloccati: `@parcel/watcher` (compila da sorgente solo se manca il binario precompilato) e `@tailwindcss/oxide` (scarica il binario solo se manca la dipendenza opzionale). La build funziona senza, quindi restano bloccati.
